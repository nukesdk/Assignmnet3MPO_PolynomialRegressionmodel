# Assignment-3: Salary Prediction using Polynomial Regression

## Objective
Develop a Polynomial Regression model to predict employee salaries based on position level.

## Dataset Link
[Position Salaries - Kaggle](https://www.kaggle.com/datasets/akram24/position-salaries)

## Libraries Used
- numpy, pandas, matplotlib, scikit-learn

## Methodology
1. Loaded & explored dataset
2. Preprocessed: missing values check, feature selection, 80/20 split
3. Polynomial Features (degree=3) + Linear Regression
4. Evaluated with MAE, MSE, R² Score
5. Visualized scatter plot + regression curve

## Results
Polynomial model captures non-linear salary progression effectively.

## Conclusion
Polynomial Regression is ideal here because salary grows non-linearly with position level, which linear regression cannot model.
